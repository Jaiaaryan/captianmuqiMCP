## Contracts to code against

- Stored chain: `McpTool.responseMapping.responseProcessing = { version:1, enabled, onError:'fail'|'passthrough', steps:[{ id, use:'currency@1'|'scale@1'|'offset@1'|'vat@1'|'round@1'|'clean_text@1'|'truncate@1'|'map@1'|'script@1' | BuiltinUse[] (pipe, 1–8, no script), each?, reads, writes, mode:'add'|'replace'|'upsert', onMissing?, params? (object; for a pipe an array aligned with use), code? }] }`. Script globals: `value` (what `reads` resolved to), `params`, `response` (the whole document), frozen `builtins.{currency,scale,offset,vat,round,clean_text,truncate,map}` (source prelude in script-runner.ts, no host refs). Limits: 32 MB, 250 ms per call, 2000 ms per response, result ≤ 1 MB, code ≤ 16 KB. Error sentence: `step <id>: $.items[3].price_usd is not a number` (pipes append ` (round@1)`). Numeric built-ins (currency/scale/offset/vat/round, steps and `builtins.*`) also map an array/object of numbers one level deep, same shape back; a bad entry names the inner path (`$.prices['A-10339'] is not a number`, `BuiltinError.key`).
- Rates (`currency@1` params `rate` | `from`+`to`, rate wins): `GET /api/response-processing/rates → { base:'EUR', asOf, source, currencies, rates, status:'live'|'cached'|'snapshot', auto, fetchedAt?, nextRefreshAt?, error? }`, `POST …/rates/refresh` (ADMIN, 2/min, 200 with `error` on failure); `RatesService` fetches the ECB daily XML out of band (lazy + >24 h + hourly tick, `RP_RATES_AUTO=false` off, `RP_RATES_URL` override), stores site setting `rp.rates`, falls back to `rates-snapshot.ts`; chain reads the table once per response. Editor: `components/tool-editor/currency-params.tsx`.
- Samples: `GET /api/response-processing/tools/:id → { chain, sampleAvailable, sampleCapturedAt?, sample?, sampleTruncated?, sampleLengths? ({'$.items':30}), sampleInput? }`. `POST /api/connectors/:cid/tools/:tid/test {arguments, recordSample:true}` stores a SUCCESS ToolInvocation (raw output ≤ 64 KB, clientInfo.source `response-processing-sample`) → answer `sampleRecorded`.
- Script parameters: JSON Schema object `{ type:'object', properties:{name:{type,description?,enum?,items?}}, required:[] }`; `{properties:{}}` = a tool with no parameters; `null` = not a tool. Names inferred from `args.x` / `args['x']` / destructuring.

## UI rules (the user's, binding)

Response Processing follows the approved specs `/tmp/amcp-shots/rp-spec-final.html` (cards, tree) and `/tmp/amcp-shots/rp-sheet-spec-final.html` (page summary + full-width sheet) (shadcn feel): `rounded-md` (6px) controls, 8px cards, no borders except the 1px `--sky` outline of an invalid card and the tree's 1px `--border` indent guides. Two surfaces: card/tree `--surface-2`, fields/params/code `--surface`. Nothing below 14px; step id 15px semibold, section title 17px; mono for paths/values/code. Colour only for state; bright `--t-*-fg` for text/icons only, filled "on" = `--ok-fill`. Icons: lucide only, through the 16px `Icon` wrapper (`components/tool-editor/icon.tsx`, optical correction scale 1.125 + 0.5px down; `size={18}` for `⋯`), in `items-center leading-none` rows; never Unicode glyphs. Zero explanatory prose (labels, verbs, numbers, codes, paths). Paths are typed or picked from the response tree; no "Advanced paths" toggle. A step card has two handles, Input and writes: Input is one path (`items[*].price_usd`, `prices[*]`, `total`, `$`) stored as `each` + `reads` split at its last `[*]` (`path-picker.tsx` `inputOf`/`splitInput`; the stored contract above is unchanged), with a `--t-info-fg` mono type label beside it, TypeScript-style (`number[30]` / `object[30]` / `mixed[30]` when walking `[*]`; else `number`, `string`, `array[30]`, `object{99}`); writes is relative to the element (`= input`, `new field`), hidden and tied when the elements are scalars; the mode follows writes (new field `add`, existing/`= input` `replace`, unknown `upsert`; a user choice stays until that flips, `followMode` in the model). In the tree every node is pickable for Input (array or object → its `[*]`; objects have a `mapScope` node `$.x[*]`, a row only when their values are objects); writes picks inside the element only. Example placeholders: `Tab` in an empty field with a placeholder accepts it (`lib/use-tab-placeholder.ts`; Monaco: ghost text `--text-3` + Tab while the model is empty), `components/ui/tab-hint.tsx` shows `Tab` (14px, `--text-3`, right end) only while empty and focused; Shift+Tab and non-empty fields keep the usual Tab. The older dense style (square, bottom-line inputs) remains for the sandbox script parameters (`TRIGGER/CELL/CONTENT/ITEM` in response-processing-styles.ts).
